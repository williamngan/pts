Changelog

Pts reaches v1.0

It has been 8 years since I released Pts.js. Life and work overwhelmed me in the few years, and instead of coding for fun, I learned to be a new parent and that was hard work too.

I asked the latest AI models to improve Pts.js and cleared years of tech debts. It worked. This brings the question whether Pts.js is still needed in 2026 and beyond. I cannot quite answer this question, except to say I still appreciate the beauty of code and I hope Pts.js will always be useful and fun for humans.

v1.0 changes

  • 10x faster: Lots of performance improvements across the board, many functions are 10x or more performant.
  • CLI: Pts.js now renders images and svgs directly in the command line. See the cli page for more.
  • New SVG renderer: SVGForm now follows the Canvas drawing API and automatically keeps SVG elements in sync between frames. It can also serve as a reference for custom renderers.
  • Feature improvements: Color now supports Oklab and Oklch. Improved image and sound handling. Revamped physics engine. Better geometry operations, animation handling, curve and voronoi and noise generation, UI tracking, and more.
  • Modernized build system: Updated to Typescript 6 in strict mode. Build scripts now use pnpm and tsdown. Packages include explicit ESM and CommonJS entry points.
  • AI ready: Documentation and guide now accessible to AI in md format. Point your agent simply to ptsjs.org and it'll follow instructions in llms.txt
  • Full test coverage. Vitest suite covering Node.js, real-browser behavior, type contracts, integrations, and visual regressions. Benchmarks established for testing.

Compatibility notes

Most API changes are additive, but corrected bugs may produce different results when old code depended on incorrect behavior. TypeScript users may also see new compile errors. See the full project changelog.

Deprecated API (but remain available):

  • HTMLSpace and HTMLForm: use SVGSpace and SVGForm.
  • Img.loadAsync: use Img.load.
  • Img.cleanup: use Img.dispose.
  • SVGForm.scope and SVGForm.updateScope: SVG elements are now reconciled automatically.
  • The initial-box form of Typography.fontSizeToBox: use fontSizeToBox(ratio, byHeight).
  • Util.randomInt: use Num.randomRange.
